## การติดตั้งและรันครั้งแรก

### Requirements

- Windows 10/11
- Python 3.10 ขึ้นไป ([ดาวน์โหลดที่นี่](https://www.python.org/downloads/)) — ตอนติดตั้งให้ติ๊ก **"Add Python to PATH"**

### ขั้นตอน

1. **โคลนโปรเจกต์** (หรือดาวน์โหลด ZIP แล้วแตกไฟล์)
   ```
   git clone https://github.com/delmoonkarn/CS460.git
   cd CS460
   ```

2. **ดับเบิลคลิกที่ `run.bat`**

   ครั้งแรกระบบจะ:
   - สร้าง virtual environment (`.venv`) — ใช้เวลาประมาณ 30 วินาที
   - ติดตั้ง dependencies จาก `requirements.txt` — ใช้เวลา 1–2 นาที
   - สร้างไฟล์ `.env` เปล่าให้อัตโนมัติ
   - เปิดเบราว์เซอร์ไปที่ http://127.0.0.1:8000

   ครั้งต่อ ๆ ไปจะเริ่มภายในไม่กี่วินาที

3. **ที่หน้า Dashboard จะมี popup ขึ้นมาให้ตั้งค่า AI Provider** (ดูหัวข้อถัดไป)

### หยุดการทำงาน

กลับไปที่หน้าต่าง command prompt ที่รัน `run.bat` แล้วกด `Ctrl+C`

## การตั้งค่า AI Provider และ API Key

ครั้งแรกที่เปิดระบบ ระบบจะบังคับให้ตั้งค่า provider ก่อนเริ่มใช้งาน (popup จะไม่สามารถปิดได้)

### เลือก Provider

| Model | Free Tier | เหมาะกับ |
|---|---|---|
| `gemini-2.5-flash` | ~15 requests/นาที | งานทั่วไป, ความแม่นยำสูง |
| `llama-3.3-70b` | ~30 requests/นาที | Batch ขนาดใหญ่ (CSV หลายร้อยรีวิว) |

### วิธีรับ API Key ฟรี

**สำหรับ Gemini:**
1. ไปที่ https://aistudio.google.com/apikey
2. ลงชื่อเข้าใช้ด้วย Google account
3. คลิก **"Create API key"** → คัดลอกค่าที่ขึ้นต้นด้วย `AIza...`

**สำหรับ Groq:**
1. ไปที่ https://console.groq.com/keys
2. สมัครฟรี (ไม่ต้องใช้บัตรเครดิต)
3. คลิก **"Create API Key"** → คัดลอกค่าที่ขึ้นต้นด้วย `gsk_...`

### วิธีตั้งค่า

1. คลิกปุ่ม **⚙️ Gemini** (หรือ **⚙️ Groq**) ที่มุมขวาบน
2. เลือก provider ที่ต้องการในกล่อง popup
3. วาง API key ในช่อง input
4. คลิก **บันทึก** — ระบบจะทดสอบ key อัตโนมัติ ถ้าใช้งานได้จะปิด popup และเริ่มใช้งานทันที

### การสลับ Provider โดยไม่ต้องวาง key ใหม่

ถ้าเคยตั้งค่าทั้ง 2 provider ไว้แล้ว สามารถสลับได้โดย:
1. คลิก **⚙️**
2. เลือก radio ของ provider ที่ต้องการ
3. กด **บันทึก** (ไม่ต้องวาง key ใหม่)

ระบบจะใช้ key เดิมที่บันทึกไว้ — ไม่ทดสอบใหม่ ไม่กิน quota

### ตำแหน่งเก็บ Key

Key ถูกบันทึกในไฟล์ `.env` ในโฟลเดอร์โปรเจกต์ **เฉพาะในเครื่องคุณเท่านั้น** — ไม่อัปโหลดไปไหน

## การจัดการร้านค้า (Stores)

ระบบรองรับการแยกข้อมูลรีวิวเป็นหลายร้าน เพื่อให้วิเคราะห์แต่ละร้านแยกกันได้

### องค์ประกอบ

ที่ส่วนหัว (header) จะมี:
```
ร้าน: [Dropdown ▼] [+ ร้าน] [×]
```

- **Dropdown** — แสดงรายชื่อร้านทั้งหมด พร้อมจำนวนรีวิวในวงเล็บ เช่น `ร้านค้าหลัก (45)`
- **+ ร้าน** — สร้างร้านใหม่
- **×** — ลบร้านปัจจุบัน (ปุ่มจะ disabled ถ้าเหลือร้านเดียว)

### สร้างร้านใหม่

1. คลิกปุ่ม **+ ร้าน**
2. กรอกชื่อร้าน (เช่น "Shopee ร้าน A", "TikTok Shop") → กด **OK**
3. ระบบจะสลับมาที่ร้านใหม่ทันที พร้อม Dashboard เปล่า

### เปลี่ยนร้านที่กำลังดู

- เลือกร้านที่ต้องการจาก dropdown
- Dashboard ทั้งหมด (stats, กราฟ, ประวัติ) จะเปลี่ยนเป็นของร้านนั้น
- ระบบจดจำร้านล่าสุดที่เลือก แม้ปิดเบราว์เซอร์แล้วเปิดใหม่

### ลบร้าน

1. เลือกร้านที่ต้องการลบใน dropdown
2. คลิกปุ่ม **×**
3. ยืนยันการลบ — **รีวิวทั้งหมดของร้านนี้จะถูกลบไปด้วย**

> ⚠️ การลบร้านลบรีวิวทั้งหมดของร้านนั้นออกถาวร ไม่สามารถกู้คืนได้

## การวิเคราะห์รีวิว

### วิธีที่ 1: วิเคราะห์รีวิวรายตัว

1. ในกล่อง **"วิเคราะห์รีวิวรายตัว"** (สีเขียว ฝั่งซ้าย)
2. วางข้อความรีวิวลงใน textarea เช่น:
   ```
   ของดีมากค่ะ ส่งไวมาก แต่กล่องบุบนิดหน่อย
   ```
3. คลิก **วิเคราะห์ด้วย AI**
4. ผลลัพธ์จะแสดงด้านล่าง:
   - **Sentiment**: positive / negative / neutral / mixed
   - **Score**: คะแนน 0–100
   - **ปัญหา (Issues)**: แท็กสีแดง
   - **ข้อดี (Positives)**: แท็กสีเขียว
   - **คำแนะนำ**: ข้อความสีเหลือง

### วิธีที่ 2: อัปโหลด CSV (Batch)

เหมาะสำหรับวิเคราะห์รีวิวจำนวนมากในครั้งเดียว

1. เตรียมไฟล์ CSV
   - คอลัมน์แรก (หรือคอลัมน์ชื่อ `review`, `text`, `comment`, `รีวิว`, `ความคิดเห็น`) คือข้อความรีวิว
   - คอลัมน์อื่นจะถูกข้าม
   - Encoding ที่รองรับ: UTF-8 (with หรือ without BOM), CP874

   ตัวอย่าง:
   ```csv
   review
   ของดีมาก ส่งไว
   สินค้าไม่ตรงปก ผิดหวัง
   รสชาติอร่อย แต่ราคาแพง
   ```

2. ในกล่อง **"อัปโหลด CSV (Batch)"** (สีฟ้า ฝั่งขวา)
3. คลิกที่กรอบเส้นประ → เลือกไฟล์ CSV
4. คลิก **อัปโหลดและวิเคราะห์**
5. ระบบจะวิเคราะห์ทีละรีวิว — สำหรับ 100 รีวิว ใช้เวลาประมาณ 1–3 นาที (ขึ้นกับ provider)

> 💡 ถ้ามีรีวิวเยอะ (> 100) แนะนำให้ใช้ **Groq (llama-3.3-70b)** เพราะ free tier สูงกว่า

### ตัวอย่าง CSV ที่มีให้ทดสอบ

ในโฟลเดอร์ `reviews samples/` มีไฟล์ตัวอย่าง:
- `sample_reviews.csv` — 20 รีวิวพื้นฐาน
- `review_shopping.csv` — 128 รีวิวจริงจากแพลตฟอร์ม e-commerce
- `review_shopping_part_01.csv` ถึง `_07.csv` — ไฟล์ข้างต้นแบ่งเป็น 7 ส่วน (~20 รีวิว/ไฟล์) เหมาะกับการทดสอบทีละชุด

## การอ่านผลใน Dashboard

### Stats Cards (แถวการ์ด 4 ใบ)

| การ์ด | ความหมาย |
|---|---|
| **รีวิวทั้งหมด** | จำนวนรีวิวของร้านปัจจุบัน (ตามตัวกรองที่เลือก) |
| **คะแนนเฉลี่ย** | ค่าเฉลี่ยของ score (0–100) |
| **Positive** | จำนวนรีวิวที่ sentiment = positive |
| **Negative** | จำนวนรีวิวที่ sentiment = negative |

### กราฟทั้ง 3

1. **การกระจาย Sentiment** (Doughnut) — สัดส่วน positive / negative / neutral / mixed
2. **Top Issues** (Bar) — ปัญหาที่ลูกค้าพูดถึงบ่อยที่สุด 10 อันดับแรก
3. **Top Positives** (Bar) — ข้อดีที่ลูกค้าพูดถึงบ่อยที่สุด 10 อันดับแรก

> 📈 ใช้ Top Issues เพื่อหาว่าควรปรับปรุงอะไรก่อน
> 📈 ใช้ Top Positives เพื่อรู้จุดแข็งที่ควรรักษาไว้

### ตารางประวัติ (Recent Analyses)

แสดงรีวิวล่าสุดสูงสุด 50 รายการ พร้อมข้อมูลทั้งหมดในแต่ละแถว:

| คอลัมน์ | คำอธิบาย |
|---|---|
| เวลา | วันและเวลาที่วิเคราะห์ (DD/MM HH:MM) |
| รีวิว | ข้อความรีวิว (ตัดให้แสดง 2 บรรทัด) |
| Sentiment | แท็กสีตาม sentiment |
| Score | คะแนน 0–100 |
| ปัญหา | แท็กสีแดง — ปัญหาที่พบ |
| ข้อดี | แท็กสีเขียว — ข้อดีที่พบ |
| คำแนะนำ | คำแนะนำเชิงธุรกิจจาก AI |

## การแก้ปัญหาที่พบบ่อย

### ❌ "127.0.0.1 refused to connect"

เซิร์ฟเวอร์ไม่ได้รัน หรือ crash ตอน startup

**วิธีแก้:**
- ดูหน้าต่าง command prompt ที่รัน run.bat — มี error message อะไรไหม
- ถ้ามี `ModuleNotFoundError` ให้ลบ `.venv\.deps_installed` แล้วรัน run.bat ใหม่ (จะติดตั้ง dependencies ใหม่)

### ❌ "วิเคราะห์ไม่สำเร็จ HTTP 502 — quota exceeded"

API key หมด quota ของวันแล้ว

**วิธีแก้:**
- รอให้ quota reset (โดยทั่วไป 24 ชั่วโมง)
- หรือสลับไปใช้อีก provider (เช่น Gemini → Groq) ผ่านปุ่ม **⚙️**

### ❌ "วิเคราะห์ไม่สำเร็จ HTTP 502 — Illegal header value"

API key มีอักขระแปลก ๆ (เช่น เว้นวรรค, อักขระพิเศษจากการ copy)

**วิธีแก้:**
- คลิก **⚙️** แล้ววาง key ใหม่อย่างระมัดระวัง (ห้ามมีเว้นวรรค หรือขึ้นบรรทัดใหม่)

### ❌ "Key looks too short"

ก๊อปปี้ key ไม่ครบ

**วิธีแก้:**
- ไปที่ console ของ provider แล้วก๊อปทั้งหมดอีกครั้ง (Gemini key ยาวประมาณ 39 ตัว, Groq key ยาวกว่า 50 ตัว)

### ❌ Dashboard ไม่อัปเดตหลังแก้ไขโค้ด

Browser cache เก่า

**วิธีแก้:**
- กด **Ctrl+F5** (hard refresh) เพื่อโหลด JS/HTML ใหม่

### ❌ Python ไม่เจอ / "python is not recognized"

Python ไม่อยู่ใน PATH

**วิธีแก้:**
- ติดตั้ง Python ใหม่จาก https://www.python.org/downloads/ — ตอนติดตั้งต้องติ๊ก **"Add Python to PATH"**
